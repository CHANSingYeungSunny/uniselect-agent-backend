## 工程现状（uniselect-cs-agent）
- 链路：CsGatewayInterceptor(merchant_id校验+转人工短路) → 防呆校验 → 意图识别(规则+小模型) → 并行ToolUse预取(3s降级) → RAG(merchant_id隔离,TopK5,100ms降级) → Prompt组装(系统规则层硬编码最高优先级+历史上下文+业务层+静态+动态+用户输入防注入) → LLM SSE流式(主备容灾) → 第二层生成中chunk扫描截断 → 第三层终检revoke → 多轮上下文(联合Key/滑动窗口/摘要/TTL) → 异步埋点。
- 所有外部依赖均 Mock/内存，接口化便于切真实 LLM/pgvector/Redis。
